# Contributing

Use the Minecraft branch and JDK version specified in `gradle.properties`.

Before submitting a pull request, run:

```sh
./gradlew build
```

Keep changes focused, follow the existing code style and include regression coverage for changes to parsing or sampling behavior. Describe the resulting behavior and how it was verified in the pull request.

For bug reports, include reproduction steps, dependency versions and relevant output from **Diagnostics → Copy details**.

Contributions are licensed under the project's [MIT license](LICENSE).
